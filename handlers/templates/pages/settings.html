How to use the API

Authentication

Send your API key in the Authorization header of every request: 

Authorization: Bearer YOUR_API_KEY

Requests with a missing or invalid key receive 401 Unauthorized. The API can upload and list files, but it can't edit or delete them.

List files

curl \
  --header "Authorization: Bearer YOUR_API_KEY" \
  {{ .BaseURL }}/api/v1/files

The response is a JSON array, sorted from newest to oldest upload: 

[
  {
    "id": "abcdefghij",
    "filename": "report.pdf",
    "url": "{{ .BaseURL }}/-abcdefghij",
    "size": 52341,
    "contentType": "application/pdf",
    "uploaded": "2026-01-01T12:00:00Z",
    "expires": "2026-01-31T12:00:00Z",
    "note": null,
    "downloadCount": 3
  }
]

expires is null for files that never expire.

Upload a file

curl \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --form "file=@report.pdf" \
  {{ .BaseURL }}/api/v1/files

Optional fields:

  • expiration URL parameter: an RFC 3339 timestamp at least one hour in the future, such as ?expiration=2026-12-31T00:00:00Z. Without it, the file uses the default expiration from these settings.
  • note form field: a note visible only to you, such as --form "note=Quarterly report".
  • downloadPassphrase form field: a passphrase that recipients must enter to download the file.

The response contains the new file's ID and download link:

{
  "id": "abcdefghij",
  "url": "{{ .BaseURL }}/-abcdefghij"
}
